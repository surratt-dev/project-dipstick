# Implementation Team Personas

Role profiles for the people involved in building and using Dipstick. Each persona captures the role's goals, concerns, and perspective to inform design and implementation decisions.

| File | Role | Motivation |
|------|------|------------|
| [Executive Stakeholder - Persona.md](Executive%20Stakeholder%20-%20Persona.md) | Executive sponsor overseeing the initiative | Wants early visibility into team health trends without surveillance, so problems surface before they become crises. |
| [Business Analyst - Persona.md](Business%20Analyst%20-%20Persona.md) | Analyst responsible for requirements and documentation | Wants requirements precise enough to build from directly, ensuring the application preserves the ritual's intent rather than producing a superficially similar substitute. |
| [Solution Architect - Persona.md](Solution%20Architect%20-%20Persona.md) | Architect designing the technical solution | Wants every significant architectural decision made explicitly and documented, with clear system boundaries and security controls built in from the start. |
| [Full Stack Engineer - Persona.md](Full%20Stack%20Engineer%20-%20Persona.md) | Engineer implementing the application | Wants a system that behaves correctly at every boundary — between frontend and backend, real-time and persistent state — and that the next engineer can maintain without tribal knowledge. |
| [Security Analyst - Persona.md](Security%20Analyst%20-%20Persona.md) | Analyst responsible for security review and compliance | Treats "internal only" as a different threat model, not a lower one, and wants authentication, authorization, and audit logging implemented correctly before the first team goes live. |
| [Facilitator - Persona.md](Facilitator%20-%20Persona.md) | Person running retrospective sessions using the tool | Wants the application to absorb cognitive overhead — readiness tracking, outlier flagging, trend visibility — so she can stay present with the team rather than managing a spreadsheet. |
| [Internal Champion - Persona.md](Internal%20Champion%20-%20Persona.md) | Advocate driving adoption within the organization | Wants the ritual to outlive his personal involvement by embedding its core mechanics and constraints in software that any team can adopt without needing him to explain it. |
