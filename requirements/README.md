# Project Dipstick — Alpha

**Dipstick** is a web application designed to facilitate recurring retrospective sessions where engineers vote on topics related to development experience and codebase health.

---

## Directory Structure

| Directory | Description |
|-----------|-------------|
| [design/](design/) | Technical design documents: database schema, persistence layer, session model |
| [use cases/](use%20cases/) | Feature-level use case documents organized by functional area |
| [implementation team personas/](implementation%20team%20personas/) | Role profiles for the people involved in building and using the system |

Each subdirectory has its own README with a full file index.
