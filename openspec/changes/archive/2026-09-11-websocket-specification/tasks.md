**Process note (per Executive review, Rachel Okonkwo):** this is a production wire-frame/dispatcher change and MUST go through the same design-review (Full Stack Engineer + Security Analyst) and implementation-review gates as any other code change in this pipeline — riding inside a docs-titled change is not grounds for a lighter pass. - [x] 2.1 Add `serverTimestamp: string` to `VoteRevealedTriggerPayload` (the Redis envelope payload, `packages/shared/src/types/realtime.ts`) and to the `vote_revealed` variant of `WsClientMessage` (the per-client wire frame, same file), per the corrected Decision D2 (Design-stage review, Marcus Oyelaran).
- [x] 2.2 In `packages/backend/src/routes/facilitator-sessions.ts`'s `POST .../reveal` handler, capture one ISO 8601 UTC timestamp after the transaction commits and pass it as `serverTimestamp` on the `VoteRevealedTriggerPayload` argument to `publishVoteRevealed`.
