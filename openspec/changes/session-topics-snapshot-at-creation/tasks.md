## Conventions

- **Unit lane stays green after every task.** A task that changes the statement sequence of a handler also updates every positional mock sequence that drives that handler, and adds mock-level tests for its own new branches. "Unit lane green" (`ci.yml`, including the 90% line gate) is an exit condition of every task in sections 1–7.
- **Real-DB tests.** Every new real-Postgres test file in this change keeps the house `describe.skipIf(!dbUp)` probe and throws when `!dbUp && process.env.REQUIRE_DB` (task 1.4). No exceptions.
- **[HUMAN]** tasks need a person (credentials, sign-off, environment access, an accountable decision). The implementing agent does not attempt them and leaves them unchecked.
- **[CONDITIONAL]** tasks are built only when the stated condition holds. The implementing agent skips them and leaves them unchecked unless the condition has been recorded as met.
- **[AT ARCHIVE]** tasks are done during archive, not during apply.
