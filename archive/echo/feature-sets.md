# Feature Sets - Engineering Health Check Application

## 1. Session Management
- Create new session with join code
- Join session via code entry
- Real-time participant list
- Session flow control (start/advance topics)
- Session state management

## 2. Topic Management
- Default health check topics
- Custom topic creation/editing
- Topic reordering
- Topic presets/templates

## 3. Voting System
- Finger voting (1-4)
- Roman voting (thumbs up/down)
- Modified Roman voting (up/flat/down)
- Simultaneous voting phase
- Vote submission and locking
- Results calculation (averages, tallies)
- Outlier detection and highlighting

## 4. Trend Visualization
- Per-topic trend charts
- Project trend sparklines
- Date range filtering
- Historical data display

## 5. Session Notes & Action Items
- Per-topic session notes
- Action item creation (description, owner, due date)
- Action item status tracking
- Action item review workflow

## 6. Team Dashboard
- Upcoming/past session list
- Current scores overview
- Trend indicators
- Quick-join for active sessions

## 7. Authentication & Access Control
- Microsoft Entra ID integration
- Role management (Participant, Facilitator, Engineering Manager)
- Team membership management
- Permission-based access

## 8. Real-Time Infrastructure
- WebSocket/SSE for live updates
- Participant presence tracking
- Vote synchronization

## 9. Facilitator Tools
- Session creation and management
- Participant readiness tracking
- Voting countdown controls
- Session note management
