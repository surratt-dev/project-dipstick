
## Vote types

### Finger Voting

Each participant holds up 1, 2, 3 or 4 fingers to communicate their response.  1 is ppor, 4 is satifactory.  This type of vote will be used when there is possible range of opinions.  

note: an even number is used to prevent an easy resposne by defaulting  a nuetral / middle answwer.  We are trying to develop an honest model the engineering team, so we don't want to allow copouts.

### Roman Vote

A simple thumbs up / thumbs down.  Down is bad, up is good.  These should be used when a binary condition is being evaluated.

### Modified Roman

A roman vote, but allowing for a flat middle hand as a neautral position.  This will only be used for vootes for trends.  For example

- thumbs down, the trend is negative.  
- flat, the trend is steady
- thumbs up, the trend is positive

Could also be a closed fist instead of an open had.

## Voting process

The facilitator will state the prompt, the vote type and the meaning of vote, then countdown from 3 to 1 and instruct the participants to vote.
